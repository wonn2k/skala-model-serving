공항 도착 여객 데이터 업로드

data/uploads/는 여기서 업로드한 CSV만 쌓이는 곳입니다. 학습(train_and_register.py 등)은 항상 가장 최근에 올라온 파일을 사용합니다. data/jeju_airport_arrivals.csv를 예시로 올려보세요 (컬럼: Date, Arrivals, Departures · 최소 41행 · 단위: 명).

드리프트 시뮬레이션

일별 변화율(log return) 기반 랜덤워크로 정상/드리프트 도착 여객 배치를 만들어 /predict/batch-test로 전송합니다. 서버가 재학습이 필요하다고 판단하면 재학습 → 배포 기준 확인 → 통과 시 새 모델 반영으로 이어집니다.

Date, Arrivals, Departures 열이 있는 연속된 날짜의 CSV를 선택하세요. 최소 41일(입력 20일 + 비교 21일)이 필요합니다. 도착 여객만 전송하며, 출발 여객은 현재 서버에서 37,000명으로 고정합니다. 이 파일은 학습 자료로 저장되지 않습니다. 재학습 시에는 위에서 업로드한 최신 학습 자료를 사용합니다.

파일을 선택하면 기간과 행 수를 확인할 수 있습니다.
