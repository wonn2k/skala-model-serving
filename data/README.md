## 기초 통계 (jeju_airport_arrivals.csv, 1,035일)

| 항목 | 값 |
|---|---|
| 도착 여객 평균 / 중앙값 | 37,218 / 37,820 명 |
| 도착 여객 표준편차 | 4,413 명 |
| 도착 여객 최소 / 최대 | 1,042 (2024-01-23 폭설) / 46,954 명 |
| 사분위 Q1 / Q3 | 34,962 / 40,177 명 → 혼잡 등급 경계 후보 |
| 출발 여객 평균 | 37,297 명 → `SIMULATED_DEPARTURES = 37_000` 근거 |
| 일별 변화율 표준편차 | 19.6% (전체) / **8.4%** (2만 명 미만 결항일 제외) |
| 전일값 그대로 예측 시 RMSE | 3,600 명 |
| 7일 이동평균 예측 시 RMSE | 3,723 명 |

**배포 게이트 2,700명**은 "전일값 복사"(3,600명)보다 약 25% 좋아야 통과하는 기준이다. LSTM이 통과하지 못하면
Sprint 1에서 (a) 게이트를 3,000~3,300으로 조정하거나 (b) test 구간(마지막 20% = 2025-04~10, 결항일 1건)의
RMSE를 근거로 재설정한다.

**드리프트 시뮬레이션 σ 주의**: `scripts/simulate_drift.py`·대시보드의 `NORMAL_SIGMA = 1.2%`, `DRIFT_SIGMA = 3.6%`는
주가 기준 값이다. 제주공항 실데이터의 일별 변동성은 8.4%라 랜덤워크 드리프트 배치(3.6%)가 실데이터보다 **더 잔잔해서**
임계값 2,700을 넘지 못할 수 있다. 시연은 `jeju_drift_batch_41rows.csv`(실데이터, 6,088명 결항일 포함)를 우선 사용하고,
랜덤워크 σ는 Sprint 1에서 실측(정상 ≈ 8%, 드리프트 ≈ 3배)으로 재조정한다.
